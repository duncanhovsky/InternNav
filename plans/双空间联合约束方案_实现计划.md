## 1. 背景与动机

### 1.1 问题诊断

Bridge-DP 当前训练效果差的根本原因：

| 问题 | 根源 |
|------|------|
| x₀-prediction 训练不稳定 | 绝对坐标值域大，不同时间步 t 的梯度量级严重不均 |
| SNR 加权数值不稳定 | `1/σ²(t)` 在低噪声区域可达 100x，少数样本主导梯度 |
| 6 项损失梯度冲突 | consistency_loss 与 action_loss 在训练初期产生对抗梯度 |

NavDP 训练稳定的原因：**ε-prediction + 增量空间 + 均匀 MSE**，三者协同使得各时间步梯度量级均匀，3 项损失梯度方向正交。

### 1.2 设计目标

- ✅ 保留布朗桥 SDE（端点约束，方向自适应方差）
- ✅ 保留绝对坐标动作空间（消除 cumsum 累积误差）
- ✅ 保留先验轨迹注入（PriorEncoder + VisualGate）
- ✅ 训练信号质量回归到 NavDP 水平（ε-prediction + 均匀 MSE）
- ✅ 额外获得增量空间的隐式平滑正则

### 1.3 核心洞察

绝对坐标和增量坐标之间存在确定性的微分关系：

$$\Delta_i = x_0[i] - x_0[i-1], \quad x_0[i] = \sum_{j=1}^{i} \Delta_j$$

对同一条轨迹，绝对空间的噪声预测和增量空间的噪声预测通过差分算子双射映射，可以在同一个网络中**联合约束**两个空间。

## 2. 核心数学框架

### 2.1 布朗桥加噪（绝对空间，保持不变）

前向加噪在绝对坐标空间进行：

$$x_t = (1-t) \cdot x_0 + t \cdot g + \sigma(t; \theta_g) \cdot \epsilon_{\text{abs}}, \quad \epsilon_{\text{abs}} \sim \mathcal{N}(0, I)$$

方向自适应方差：

$$\sigma^2(t;\theta_g) = \sigma^2_{\text{base}} \cdot [t(1-t)]^{p(\theta_g)} + t^2 \cdot \sigma^2_{\text{goal}}, \quad p(\theta_g) = 0.5 + 0.3\cos\theta_g$$

### 2.2 增量空间的含噪信号

对 $x_t$ 施加差分算子 $D$：

$$D(x_t)[i] = (1-t) \cdot D(x_0)[i] + t \cdot \underbrace{D(g)[i]}_{=0} + \sigma(t;\theta_g) \cdot D(\epsilon_{\text{abs}})[i]$$

因为目标 $g$ 广播到每个时间步，$D(g) = 0$，所以：

$$D(x_t)[i] = (1-t) \cdot D(x_0)[i] + \sigma(t;\theta_g) \cdot \underbrace{D(\epsilon_{\text{abs}})[i]}_{\epsilon_{\text{rel}}[i]}$$

增量空间的噪声目标：

$$\epsilon_{\text{rel}}[i] = \epsilon_{\text{abs}}[i] - \epsilon_{\text{abs}}[i-1], \quad i = 1, \ldots, T-1$$

虽然 $\epsilon_{\text{rel}}$ 不是独立高斯（$\text{Cov}(\epsilon_{\text{rel}}[i], \epsilon_{\text{rel}}[i+1]) = -\sigma^2 I$），但均值为零，MSE 损失仍然有效。

### 2.3 双预测头训练目标

网络共享同一个 Transformer Decoder，输出两个预测头：

| 预测头 | 预测目标 | 空间 | 对应现有模块 |
|--------|---------|------|------------|
| `action_head` | $\hat{\epsilon}_{\text{abs}}$（绝对空间噪声） | 绝对坐标 | 复用，改变语义 |
| `delta_head` | $\hat{\epsilon}_{\text{rel}}$（增量空间噪声） | 增量坐标 | 复用，改变语义 |

### 2.4 总损失函数

$$\mathcal{L}_{\text{total}} = 0.8 \cdot \mathcal{L}_{\text{action}} + 0.2 \cdot \mathcal{L}_{\text{critic}} + 0.5 \cdot \mathcal{L}_{\text{aux}}$$

动作损失（双空间联合）：

$$\mathcal{L}_{\text{action}} = 0.5 \cdot \mathcal{L}_{\text{ng}} + 0.5 \cdot \mathcal{L}_{\text{mg}}$$

$$\mathcal{L}_{\text{ng}} = \alpha \cdot \underbrace{\| \hat{\epsilon}^{\text{abs}}_{\text{ng}} - \epsilon_{\text{abs}} \|^2}_{\text{绝对空间 ε-MSE}} + (1-\alpha) \cdot \underbrace{\| \hat{\epsilon}^{\text{rel}}_{\text{ng}} - \epsilon_{\text{rel}} \|^2}_{\text{增量空间 ε-MSE}}$$

推荐初始值 $\alpha = 0.5$（均等权重）。

**关键特性**：总损失仍为 3 项，与 NavDP 完全同构，无需 SNR 加权、valid_mask 加权、terminal_loss、consistency_loss、smoothness_loss。

### 2.5 推理时 ε → x₀ 反解

已知 $x_t$、$t$、$g$、$\theta_g$ 和网络预测的 $\hat{\epsilon}_{\text{abs}}$，反解干净轨迹：

$$\hat{x}_0 = \frac{x_t - t \cdot g - \sigma(t;\theta_g) \cdot \hat{\epsilon}_{\text{abs}}}{1 - t}$$

数值保护：当 $t \to 1$ 时分母趋零，用 `clamp(min=0.01)` 防止爆炸；最后一步（$t \leq \Delta t$）直接返回 $\hat{x}_0$（与 `BridgeScheduler.step` 现有逻辑一致）。

## 3. 解空间分析

### 3.1 梯度互补性

绝对空间损失的梯度作用于**每个轨迹点独立**：

$$\frac{\partial \mathcal{L}_{\text{abs}}}{\partial \hat{\epsilon}^{\text{abs}}[i]} = 2(\hat{\epsilon}^{\text{abs}}[i] - \epsilon_{\text{abs}}[i])$$

增量空间损失的梯度**连接相邻轨迹点**：

$$\frac{\partial \mathcal{L}_{\text{rel}}}{\partial \hat{\epsilon}^{\text{abs}}[i]} = 2(\hat{\epsilon}^{\text{rel}}[i] - \epsilon_{\text{rel}}[i]) - 2(\hat{\epsilon}^{\text{rel}}[i+1] - \epsilon_{\text{rel}}[i+1])$$

两种梯度互补：
- 绝对梯度保证每个点的**全局定位精度**
- 增量梯度保证相邻点的**相对运动一致性**

### 3.2 增量损失的隐式正则效果

增量空间 ε-MSE 等价于惩罚相邻帧噪声预测的差异，自然提供：

1. **局部平滑性**：替代人工的 `smoothness_loss`（加速度正则）
2. **一致性约束**：数学上 $\epsilon_{\text{rel}} = D(\epsilon_{\text{abs}})$ 自然保证，替代人工的 `consistency_loss`

### 3.3 与 NavDP 的解空间同构性

| 性质 | NavDP | 双空间 Bridge-DP |
|------|-------|-----------------|
| 预测目标值域 | ε ~ N(0, I)，紧凑 | ε_abs ~ N(0, I)，ε_rel ~ N(0, 2I)，紧凑 |
| MSE 加权 | 均匀 | 均匀，无需 SNR 加权 |
| 梯度量级 | 各 t 均匀 | 各 t 均匀 |
| 损失项数 | 3 项 | 3 项（相同结构） |
| 额外正则 | 无 | 增量损失提供隐式正则，无额外超参 |

### 3.4 方向自适应方差的保留价值

布朗桥的方向自适应方差 $\sigma^2(t;\theta_g)$ 在 ε-prediction 模式下仍然有效：

- 训练时：不同 $\theta_g$ 的样本有不同的加噪强度，网络学会在不同方向场景下的噪声分布
- 推理时：反解公式 $\hat{x}_0 = (x_t - t \cdot g - \sigma \cdot \hat{\epsilon}) / (1-t)$ 中 $\sigma$ 仍然参与，方向自适应特性完整保留

### 4.2 `bridgedp_policy.py` 修改要点

#### (1) `sample_bridge_noise` — 返回 noise 而非 x₀

```python
def sample_bridge_noise(self, x0, goal, theta_g, timesteps=None):
    device = x0.device
    B = x0.shape[0]
    if timesteps is None:
        timesteps = torch.randint(
            0, self.bridge_scheduler.config.num_train_timesteps,
            (B,), device=device
        ).long()
    time_embeds = self.time_emb(timesteps).unsqueeze(1)
    noise = torch.randn_like(x0)
    noisy_action = self.bridge_scheduler.add_noise(x0, goal, theta_g, timesteps, noise)
    noisy_action_embed = self.input_embed(noisy_action)
    # 改：返回 noise（训练目标），而非 x0
    return noise, time_embeds, noisy_action_embed, timesteps
```

#### (2) `forward` — 双头输出 ε_abs 和 ε_rel

```python
def forward(self, goal_point, goal_image, goal_pixel,
            input_images, input_depths,
            output_actions, augment_actions,
            prior_traj, theta_g):
    # ... 加噪：返回 noise ...
    ng_noise, ng_time_embed, ng_noisy_embed, _ = self.sample_bridge_noise(
        tensor_label_actions, tensor_point_goal, tensor_theta_g
    )
    mg_noise, mg_time_embed, mg_noisy_embed, _ = self.sample_bridge_noise(
        tensor_label_actions, tensor_point_goal, tensor_theta_g
    )

    # ... 视觉编码、先验处理保持不变 ...

    # Decoder 前向
    ng_output = self.decoder(tgt=ng_action_embeddings, memory=ng_cond_embeddings, tgt_mask=self.tgt_mask)
    ng_output = self.layernorm(ng_output)
    eps_abs_pred_ng = self.action_head(ng_output)   # 绝对空间噪声预测 (B, T, 3)
    eps_rel_pred_ng = self.delta_head(ng_output)    # 增量空间噪声预测 (B, T, 3)，取前 T-1 步

    mg_output = self.decoder(tgt=mg_action_embeddings, memory=mg_cond_embeddings, tgt_mask=self.tgt_mask)
    mg_output = self.layernorm(mg_output)
    eps_abs_pred_mg = self.action_head(mg_output)
    eps_rel_pred_mg = self.delta_head(mg_output)

    # Critic 保持不变 ...

    # 计算增量空间的噪声目标 D(ε_abs)
    ng_noise_rel = ng_noise[:, 1:, :] - ng_noise[:, :-1, :]  # (B, T-1, 3)
    mg_noise_rel = mg_noise[:, 1:, :] - mg_noise[:, :-1, :]

    return (eps_abs_pred_ng, eps_abs_pred_mg,
            eps_rel_pred_ng, eps_rel_pred_mg,
            cr_label_pred, cr_augment_pred,
            ng_noise, mg_noise,
            ng_noise_rel, mg_noise_rel,
            imagegoal_aux_pred, pixelgoal_aux_pred)
```

#### (3) 新增 `_eps_to_x0` 推理反解方法

```python
def _eps_to_x0(self, eps_pred, x_t, timestep, goal, theta_g):
    """从 ε 预测反解 x₀：x₀ = (x_t - t·g - σ·ε) / (1-t)"""
    t = self.bridge_scheduler._normalized_time(timestep).float()
    while t.dim() < x_t.dim():
        t = t.unsqueeze(-1)
    sigma = self.bridge_scheduler.std(t, theta_g.view(-1, 1, 1))
    if goal.dim() == 2:
        goal = goal.unsqueeze(1).expand_as(x_t)
    return (x_t - t * goal - sigma * eps_pred) / (1 - t).clamp(min=0.01)
```

#### (4) 推理循环修改

```python
# predict_pointgoal_batch_action_vel 中的去噪循环
```

### 4.3 `bridgedp_trainer.py` 损失函数重写

```python
def compute_loss(self, model, inputs, return_outputs=False, ...):
    # ... 输入搬运不变（保留 batch_prior, batch_theta_g, batch_valid_mask）...

    (eps_abs_pred_ng, eps_abs_pred_mg,
     eps_rel_pred_ng, eps_rel_pred_mg,
     critic_pred, augment_pred,
     ng_noise, mg_noise,
     ng_noise_rel, mg_noise_rel,
     imagegoal_aux_pred, pixelgoal_aux_pred) = model(...)

    # ══ 双空间 ε-MSE（均匀，无 SNR 加权）══
    alpha = getattr(self.config.il, 'alpha_dual_space', 0.5)

    ng_abs_loss = (eps_abs_pred_ng - ng_noise).square().mean()
    mg_abs_loss = (eps_abs_pred_mg - mg_noise).square().mean()
    ng_rel_loss = (eps_rel_pred_ng[:, :-1, :] - ng_noise_rel).square().mean()
    mg_rel_loss = (eps_rel_pred_mg[:, :-1, :] - mg_noise_rel).square().mean()

    ng_action_loss = alpha * ng_abs_loss + (1 - alpha) * ng_rel_loss
    mg_action_loss = alpha * mg_abs_loss + (1 - alpha) * mg_rel_loss
    action_loss = 0.5 * ng_action_loss + 0.5 * mg_action_loss

    # ══ 辅助损失（与 NavDP 完全一致）══
    aux_loss = (0.5 * (batch_pg - imagegoal_aux_pred).square().mean()
              + 0.5 * (batch_pg - pixelgoal_aux_pred).square().mean())

    # ══ Critic 损失（与 NavDP 完全一致）══
    critic_loss = ((critic_pred - batch_label_critic).square().mean()
                 + (augment_pred - batch_augment_critic).square().mean())

    # ══ 总损失：3 项，与 NavDP 完全同构 ══
    loss = 0.8 * action_loss + 0.2 * critic_loss + 0.5 * aux_loss

    # 完全移除：SNR 加权、valid_mask 加权、terminal_loss、
    #          consistency_loss、smoothness_loss
```

## 5. 优劣与风险评估

### 5.1 优势总结

| 优势 | 说明 |
|------|------|
| 训练信号与 NavDP 同构 | 双头都预测噪声 ε，均匀 MSE，无需 SNR 加权，训练稳定性与 NavDP 一致 |
| 保留布朗桥全部创新 | 加噪/去噪仍走布朗桥，端点约束和方向自适应方差完整保留 |
| 保留绝对坐标 | 推理输出直接是绝对轨迹，无 cumsum 累积误差 |
| 保留先验轨迹注入 | PriorEncoder + VisualGate 不受影响，`use_prior_traj=True` 时可直接启用 |
| 隐式平滑正则 | 增量空间损失自然惩罚相邻帧跳跃，替代人工的 smoothness_loss |
| 超参极简 | 仅新增 1 个超参 α，总损失仍为 3 项 |
| 复用现有 delta_head | 改变语义但不改变结构，无需新增参数 |

### 5.2 风险与应对

| 风险 | 严重度 | 应对策略 |
|------|--------|---------|
| ε → x₀ 反解中 (1-t)→0 数值不稳定 | 低 | `clamp(min=0.01)`；最后一步直接返回 x₀（已有保护） |
| ε_rel 不是独立高斯 | 低 | 均值为零、方差有界(=2σ²)，MSE 仍然有效 |
| delta_head 语义改变需要重训 | 中 | 需从头训练，不能加载旧的 delta_head 权重 |
| α 最优值未知 | 低 | 消融实验：α ∈ {0.3, 0.5, 0.7} |

### 5.3 与现有方案 C 的对比

| 维度 | 方案 C（当前） | 双空间 ε-prediction（本方案） |
|------|--------------|--------------------------|
| 预测目标 | action_head→x̂₀，delta_head→Δ | action_head→ε_abs，delta_head→ε_rel |
| 一致性约束 | 显式 consistency_loss | 数学自然保证（ε_rel = D(ε_abs)） |
| 平滑约束 | 显式 smoothness_loss | 增量 MSE 隐式提供 |
| 总损失项 | 6 项（含 SNR 加权） | 3 项（均匀 MSE） |
| 训练稳定性 | 差（多项竞争约束） | 好（与 NavDP 同构） |
| 推理 | 直接输出 x̂₀ | ε→x₀ 反解（多一步除法，数值稳定） |

### 5.4 消融实验建议

| 实验 | 目的 |
|------|------|
| α = 0.3 / 0.5 / 0.7 | 确定绝对/增量空间的最优权重比 |
| 仅绝对空间（α=1.0） | 验证增量损失的贡献 |
| 仅增量空间（α=0.0） | 验证绝对损失的贡献 |
| 与 NavDP 对比 | 验证双空间方案是否超越基线 |
